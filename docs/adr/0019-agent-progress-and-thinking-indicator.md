# ADR 0019：计划进度卡片与“正在思考”指示

- 状态：已采纳（2026-11-18）

## 背景

计划进度原先挤在输入框上沿的唇条正中，只显示当前步骤，全部步骤要悬停才看得到；“正在思考”是星光图标加透明度呼吸。用户要求两者分别照 BoardUI 的「智能体任务进度」（agent-progress）与「智能体思考状态」（agent-thinking）模板改版，并确认了效果图，进度卡片默认收起。

BoardUI 是付费组件，模板依赖 motion。项目不新增依赖，也不照抄模板源码，按线上预览观察到的尺寸、时序与行为自己实现。

## 决定

### 计划进度卡片（`features/chat/agent-progress.tsx`）

- 位置：输入框上方、唇条之上的独立卡片（宽 341px，窄窗口时不超过容器）。唇条只保留分支与工作区，旧的 `TodoProgress` / `TodoMark` 删除。有工具确认、提问、计划审批卡时进度卡让位。
- 默认收起成一行：总进度环 +“还剩 N 步”+ 箭头 + 当前步骤（流光），悬停出现展开图标，整行可点。展开后头部为进度环 + 标题 + 收起按钮，下面列出全部步骤。展开状态按会话标签各自记住（组件按 tabId 重建）。
- 尺寸照模板：收起 44px，展开 45 + 38·N（行高 32、间距 6），超过 8 步高度封顶、列表内部滚动并把当前步骤滚进视野。
- 动画全部用 CSS：卡片高度过渡（展开 650ms、收起 420ms，缓动 cubic-bezier(0.22, 1, 0.36, 1)），两层内容交叉淡入加模糊；当前步骤的胶囊边框是一个随当前步骤平移的元素（代替 motion 的 layoutId）；完成的步骤打勾弹入、删除线从左划出；跳过的步骤为虚线圆加斜杠；标题文字切换时自下而上去模糊出现。
- 有意偏离模板：总进度环按真实完成比例推进（跳过算完成），模板按预设总时长线性走；真实步骤没有固定时长。
- 全部完成后显示“全部步骤已完成”，停 1.8 秒后淡出；之后清单换了或又出现未完成步骤时重新显示。
- 减少动态效果时关闭所有 keyframes 与流光。

### 正在思考（`features/chat/thinking-wave.tsx`）

- 采用 wave 变体：3×3 个 4px 小方点，间距 2px，每个点峰值后按 (1 − x/0.3)^1.5 衰减到 0.12，一轮 640ms，相位 (列 + 行)/4 × 0.75。模板用 80ms 定时器改透明度；这里用一条 CSS keyframes 加负延迟错开相位，不触发 React 重渲染。
- 文字流光 2.6s（两侧为次要文字色 55% 混合），右侧等宽计时，0.1 秒一跳，从指示出现起算。
- 用在两处：回复开始前的占位（`ThinkingIndicator`）与时间线里进行中的思考步骤（仍可展开看思考内容）。原星光图标动画（think-spark）删除。

## 后果

- 流光是 background-clip:text 的渐变平移，每帧重绘文字。text-pulse 的注释记录过它叠在磨砂玻璃上让 WebView2 GPU 持续高占用；这里只用在一行短文字上并加 contain:paint 限制重绘范围，仍需在 Windows 实机观察 GPU 占用，不理想时退回透明度呼吸。
- 计时从组件挂载算起：中途重新打开会话时从 0 开始。
- 动画只在 jsdom 里验证了结构与状态，真实观感要在 Windows 上确认。
